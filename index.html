Sheet data

Import or export sheet data as JSON. You can also paste a card list below.

JSON format help 
[
  {
    "name": "Three Days Grace",
    "year": "1997",
    "genre": "Alt-Rock",
    "place": "Canada",
    "abbreviation": "TDG",
    "photo": "https://example.com/band.jpg"
  }
]
Only name is required. photo accepts data:image/... and https://... URLs. Optional fields include accent, photoZoom, photoX/photoY, theme, stampShape, stampText, or a full settings + cards payload. Maximum 300 cards.
